# 🎮 Tic Tac Toe Game

A simple and interactive **Tic Tac Toe game** built using **HTML, CSS, and JavaScript**.  
This project is designed to demonstrate core front-end development skills and basic game logic implementation.

---

## 🚀 Live Demo
👉 [Click here to play](https://banavathuramkumar.github.io/Tic-Tac-Toe---game-mini-project-) 

---

## 📌 Features

- 🎯 Two-player game (Player X and Player O)
- 🧠 Smart win/draw detection logic
- 🔄 Automatic turn switching
- 📱 Responsive design for mobile and desktop
- 🎨 Clean and minimal UI design
- 🔁 Restart game option

---

## 🛠️ Technologies Used

- HTML5 – Structure of the game
- CSS3 – Styling and layout
- JavaScript (ES6) – Game logic and interactivity

---

## 📂 Project Structure
```
Tic-Tac-Toe/
│── index.html # Main HTML file
│── style.css # Styling file
│── script.js # Game logic
```


---

## 🎮 How to Play

1. Open the game in your browser  
2. Player X starts first  
3. Click on any empty box to make a move  
4. Players take turns until someone wins or the game ends in a draw  
5. Click "Restart" to play again
